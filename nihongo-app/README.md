# 일본어 말하기 (안드로이드 앱)

일본어 **말하기 연습**에 집중한 안드로이드 앱입니다. 문장을 듣고 → 따라 말하면 → 음성 인식으로 점수를 매겨 줍니다.

**APK 다운로드:** [`release/nihongo-speaking.apk`](release/nihongo-speaking.apk)

## 기능

- **따라 말하기**: 원어민 음성(TTS)을 듣고 그대로 따라 말하기, 천천히 듣기 지원
- **보고 말하기**: 한국어 뜻만 보고 일본어로 말하기 (첫 글자 힌트 / 정답 보기)
- **발음 채점**: 음성 인식 결과와 비교해 0~100점, 틀린 글자는 빨간색으로 표시
- **회화 롤플레이 13편**: 상대 역할은 앱이, 내 대사는 내가 말하기 (역할 바꾸기 가능)
- **히라가나·가타카나**: 글자표(누르면 발음), 읽기 퀴즈, 듣기 퀴즈
- **복습 / 즐겨찾기 / 랜덤 10문장 / 빠른 말하기**
- 모든 문장에 히라가나 읽기, 로마자, 한글 발음 표시 (설정에서 끄기 가능)
- 오늘 말한 문장 수, 연속 학습일, 레슨별 진도 저장

## 학습 내용 (37개 레슨 · 877문장 + 회화 13편)

| 단계 | 레슨 |
| --- | --- |
| 0 기초 발음 | 청음 단어, 탁음·반탁음, 요음·촉음·장음, 가타카나 외래어 |
| 1 첫걸음 | 인사, 감사·사과·대답, 자기소개, 숫자, 시간·요일·날짜, 이것·저것, 가족 |
| 2 기본 문형 | です, ます, ました, たい/ましょう, てください, あります/います, 형용사, 질문, ています, 허락·금지·의무, 가능·경험, 의견·이유·추측 |
| 3 생활 회화 | 식당·카페, 쇼핑, 길 묻기·교통, 호텔, 공항·여행, 날씨, 병원·약국, 전화·약속 |
| 4 자연스러운 대화 | 취미, 감정 표현, 친구와 반말, 맞장구, 집·일상, 직장 기본 |

## 휴대폰 준비

1. **음성(TTS)**: 설정 → 텍스트 음성 변환 → Google 음성 엔진 → 일본어 음성 데이터 설치
2. **음성 인식**: Google 앱이 필요하고 보통 인터넷 연결이 필요합니다. Google 앱 → 설정 → 음성 → 언어에 일본어를 추가하면 더 정확합니다.
3. 음성 인식이 없는 기기에서는 자동으로 **스스로 평가** 모드로 바뀝니다.

## 내용 추가하는 법

문장은 `assets/data/*.js`에 있습니다. 새 레슨은 이렇게 추가합니다:

```js
LESSONS.push({
  id: 'x01', level: 3, icon: '🎌', title: '레슨 제목', desc: '짧은 설명',
  tip: '(선택) 레슨 팁',
  items: [
    // [일본어, 읽기(단어마다 띄어쓰기, 조사 は・へ・を는 따로), 한국어 뜻, 팁(선택), [추가 정답](선택)]
    ['駅はどこですか', 'えき は どこ ですか', '역은 어디예요?'],
  ]
});
```

## 빌드

Android SDK 없이 `aapt`, `dx`, `zipalign`, `apksigner`로 빌드합니다.

```bash
sudo apt-get install aapt dalvik-exchange zipalign apksigner   # JDK 필요
./build.sh    # → release/nihongo-speaking.apk
```

`keystore/nihongo.keystore`는 업데이트 설치(같은 서명)를 위해 저장소에 함께 둡니다. 개인 학습용 키입니다.
