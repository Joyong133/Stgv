# 단잠 🌙 — 빗소리 · 수면 사운드 앱

온갖 빗소리와 잠들기 좋은 자연·생활 소리 37가지를 골라 **섞어서** 들을 수 있는 안드로이드 앱입니다.
소리는 녹음 파일이 아니라 앱 안에서 **실시간으로 합성**합니다. 그래서 APK가 약 100KB로 작고,
몇 시간을 틀어 두어도 같은 구간이 되풀이되지 않습니다.

## 설치

1. [`release/danjam.apk`](release/danjam.apk)를 휴대폰으로 내려받습니다.
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다.
3. Android 7.0 이상에서 동작합니다.

## 기능

- **섞어 듣기**: 타일을 누르면 켜지고 다시 누르면 꺼집니다. 켜진 소리마다 음량 막대가 생깁니다.
- **추천 믹스 12가지**: 비 오는 날 캠핑, 폭풍우 치는 밤, 여름밤 시골집, 산사의 밤, 아기 재우기 …
- **내 믹스 저장**: 지금 듣는 조합에 이름을 붙여 저장하고 한 번에 다시 틉니다. 길게 누르면 삭제.
- **잠들기 타이머**: 10분 ~ 8시간. 끝나기 1분 전부터 소리가 천천히 작아진 뒤 꺼집니다.
- **화면이 꺼져도 재생**: 알림창과 잠금화면에서 재생/일시정지/끄기를 할 수 있습니다.
- 이어폰을 뽑으면 멈추고, 전화가 오면 잠시 멈췄다가 통화가 끝나면 다시 재생합니다.
- 마지막으로 듣던 조합과 음량을 기억합니다.

모든 소리는 체감 음량(LUFS)을 측정해 서로 비슷한 크기로 맞춰 두었습니다.

## 소리를 만드는 방법

`app/src/main/java/com/joyong133/danjam/audio/` 에 합성기가 있습니다 (안드로이드에 의존하지 않는 순수 자바).

- **빗소리** (`RainGen`): 멀리서 쏟아지는 '쏴아' 바탕 소리, 가까이 떨어지는 빗방울의 '톡톡',
  빗방울이 두드리는 표면(양철·유리·천막·자동차 지붕)이 짧게 울리는 소리, 웅덩이 기포와 처마 낙숫물을
  층별로 조합합니다. 비 종류마다 각 층의 세기와 음색이 다릅니다.
- **물방울·기포** (`Bubbles`): 주파수가 살짝 올라가며 사라지는 사인파(민나어트 공명)로 시냇물, 낙숫물, 물속 기포를 만듭니다.
- **새·개구리** (`Chirps`): 높이가 미끄러지는 짧은 음에 떨림과 펄스를 더해 지저귐과 울음을 만듭니다.
- **싱잉볼·풍경·오르골** (`Rings`): 배음마다 다른 속도로 사라지는 공명음.
- `Mixer`가 여러 소리를 섞고, 공용 잔향을 더한 뒤, 리미터로 소리가 깨지지 않게 합니다.

## 직접 빌드하기

**Android Studio**: `sleep-sounds` 폴더를 열고 실행하면 됩니다.

**명령줄 (Gradle)**:

```sh
cd sleep-sounds
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

**명령줄 (Gradle 없이)**: Android SDK 도구(aapt2, d8 또는 dx, zipalign, apksigner)만 있으면 됩니다.

```sh
cd sleep-sounds
ANDROID_JAR=$ANDROID_HOME/platforms/android-35/android.jar tools/build-apk.sh   # release/danjam.apk
```

`sleep-sounds/` 아래가 바뀌어 푸시되면 GitHub Actions(`.github/workflows/sleep-sounds-apk.yml`)가
APK를 빌드해 아티팩트로 올립니다.

## 서명 키에 대해

`keystore/danjam.jks`는 **개인 설치용** 키입니다. 같은 키로 서명해야 새 버전을 지우지 않고 덮어 설치할 수 있어서
저장소에 함께 넣어 두었습니다. 저장소가 공개되어 있으면 누구나 이 키로 서명할 수 있으니,
Play 스토어 등에 배포할 때는 새 키를 만들어 따로 보관하세요.

## 파일 구성

```
app/src/main/java/com/joyong133/danjam/
  MainActivity.java   소리 고르기 화면 (분류 탭, 타일, 믹스, 재생 막대, 타이머)
  SoundService.java   백그라운드 재생, 타이머, 알림 · 잠금화면 컨트롤, 오디오 포커스
  AudioEngine.java    오디오 스레드 (믹서 → AudioTrack)
  MixStore.java       마지막 조합과 저장한 믹스 보관
  audio/              소리 합성기와 믹서, 소리 목록(SoundCatalog), 추천 믹스(Presets)
app/src/main/res/     아이콘, 테마, 문자열
tools/build-apk.sh    Gradle 없이 APK 빌드
release/danjam.apk    빌드된 설치 파일
```
