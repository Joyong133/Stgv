# 텍스트 영상 메이커 (Android)

TXT 파일(또는 붙여넣은 글)을 **사람 목소리에 가까운 여성 음성으로 읽어 주고**, 그 낭독을 그대로 **자막 영상(MP4)** 으로 만들어 주는 안드로이드 앱입니다.

## 설치

1. 저장소의 **Releases → `textvideo-latest`** 에서 `TextVideo.apk` 를 휴대폰으로 받습니다.
   (또는 Actions 탭의 최신 `TextVideo APK build` 실행 → Artifacts `TextVideo-apk`)
2. 받은 파일을 누르고 "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
3. Android 8.0 이상에서 동작합니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| TXT 불러오기 | 📂 버튼, 파일 관리자의 "다른 앱으로 열기", 다른 앱의 "공유" 모두 지원. UTF-8 / UTF-16 / 한국어 윈도우(CP949·EUC-KR) 인코딩 자동 판별 |
| 목소리 스타일 | 기본 · 🐰 귀엽게 · 🧒 아이 · 차분히 버튼. 같은 무료 목소리의 음 높이와 속도를 바꿔 느낌을 바꿈 |
| 읽어 주기 | 문장 단위로 읽으며 지금 읽는 문장을 노란색으로 표시. 멈춤 → 이어 읽기, 속도·음높이 조절 |
| 여성 목소리 자동 추천 | 설치된 목소리 중 **한국어 → 여성 → 음질 → 온라인 신경망 음성** 순으로 점수를 매겨 가장 사람 같은 목소리를 ★ 추천으로 자동 선택 |
| 영상 만들기 | 문장마다 장면을 만들고 목소리 길이에 맞춰 넘어가는 MP4(H.264 + AAC) 생성. 세로 9:16(쇼츠·릴스) / 가로 16:9(유튜브), 1080p / 720p, 배경 테마 6종, 제목·쪽수·진행 막대·페이드 효과 |
| 저장·공유 | 갤러리의 `Movies/TextVideo` 폴더에 저장, 바로 재생·공유 |

## 목소리 고르기 팁

- **기본(무료)**: 휴대폰의 *Google 음성 서비스(Speech Services by Google)* 를 씁니다. 한국어 여성 목소리 중 `ko-kr-x-ism` 계열이 가장 자연스럽고, 특히 **"온라인"** 표시가 붙은 목소리는 서버의 신경망 음성이라 더 사람 같습니다. 앱이 이것을 자동으로 ★ 추천합니다.
  - 목소리가 안 나오거나 "다운로드 필요"가 보이면 **목소리 다운로드·설정** 버튼 → 목소리 데이터를 받아 주세요.
- **최고 음질(선택)**: 음성 엔진에서 **☁ Google Cloud 최고음질** 을 고르고 Google Cloud Text-to-Speech API 키를 넣으면 **Chirp 3 HD** 여성 목소리(Aoede 등)를 쓸 수 있습니다. 실제 사람과 거의 구별이 어려운 수준이지만, Google Cloud 계정이 필요하고 사용량에 따라 요금이 나올 수 있습니다. 키는 휴대폰에만 저장됩니다.

## 직접 빌드

```bash
cd text2video
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

`text2video/` 아래를 수정해 푸시하면 GitHub Actions 가 자동으로 APK 를 빌드해 `textvideo-latest` 릴리스에 올립니다.
서명 키(`app/textvideo.keystore`, 비밀번호 `textvideo`)는 개인 설치용으로 저장소에 포함되어 있어, 새 버전을 기존 앱 위에 덮어 설치할 수 있습니다.
