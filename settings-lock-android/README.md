# 설정 잠금 (Android)

정해 둔 시간 동안 휴대폰의 **설정 앱에 못 들어가게** 막는 안드로이드 앱입니다.
잠금 중에 설정을 열면(알림창 톱니바퀴 포함) 바로 홈 화면으로 돌아갑니다. 홈 화면을 길게 눌러 들어가는 **홈 화면 설정**도 막습니다.

## 받기

- APK: <https://github.com/Joyong133/Stgv/releases/download/settings-lock/SettingsLock.apk>
- `settings-lock-android/` 아래 코드가 바뀌어 푸시되면 GitHub Actions가 자동으로 다시 빌드해서 위 주소에 올립니다.

## 처음 설정

1. APK를 받아 설치합니다. 출처를 알 수 없는 앱 설치를 허용하라고 나오면 허용하세요.
2. 앱을 열고 **접근성 설정 열기** → 설치된 앱 → **설정 잠금** 켜기.
   - 스위치가 회색이라 안 켜지면 (안드로이드 13 이상): 앱의 **이 앱 정보 열기** → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켜기.
3. 시간을 고르고 **잠금 시작**.

## 동작

- 잠금 시간: 1분 ~ 168시간(7일). 빠른 선택 버튼(10분 · 30분 · 1시간 · 3시간 · 8시간 · 하루)도 있습니다.
- 잠금 중에는 끄거나 줄일 수 없고, 시간을 **더하는 것만** 됩니다.
- 옵션: 잠금 중 **앱 설치/삭제 화면도 막기** (이 앱을 지워서 잠금을 푸는 걸 막음). 잠금 중에는 다른 앱 설치도 막힙니다.
- 휴대폰을 재부팅해도 잠금이 유지됩니다.
- 접근성 서비스는 "화면 바뀜" 이벤트(어떤 앱의 어떤 화면이 떴는지)만 보고, 화면 내용은 읽지 않습니다.
- 홈 화면 설정은 홈 화면 앱(런처) 안에서 이름에 `Settings`가 들어간 화면이 뜨면 막습니다. 런처가 설정 화면에 다른 이름을 쓰면 안 막힐 수 있습니다.

## 기타 기능: 카메라 · Play 스토어 · 카카오톡 인앱 브라우저 막기

- **잠금화면에서 카메라 못 쓰게 하기**: 휴대폰이 잠긴 상태에서 카메라가 열리면(잠금화면 카메라 버튼, 전원 버튼 두 번 누르기 등) 바로 닫고 잠금화면으로 돌아갑니다.
- **잠금을 푼 상태에서도 카메라 앱 못 쓰게 하기**: 휴대폰 기본 카메라 앱을 언제든 막습니다. 다른 앱이 기본 카메라 앱을 불러 사진을 찍는 경우도 막힙니다. (앱 안에 카메라를 직접 넣은 카카오톡·인스타그램 같은 앱 속 카메라는 막지 않습니다.)
- **Play 스토어 못 쓰게 하기**: Play 스토어가 열리면 바로 홈 화면으로 돌아갑니다. 다른 앱 안에서 뜨는 Play 스토어 창(앱 안 결제, 리뷰 창 등)도 막힙니다. 앱 자동 업데이트는 그대로 됩니다.
- **카카오톡 인앱 브라우저 못 쓰게 하기**: 카카오톡에서 링크를 눌러 뜨는 웹 화면이 열리면 '뒤로 가기'로 바로 닫습니다. 카카오톡 대화는 그대로 쓸 수 있습니다. 카카오톡 안에서 화면 이름에 `Browser`·`WebView`가 들어간 화면을 막는 방식이라, 카카오톡이 업데이트로 화면 이름을 바꾸면 안 막힐 수 있습니다.
- 시간 잠금과 상관없이 체크해 두는 동안 계속 작동합니다. 체크는 시간 잠금 중에도 언제든 켜고 끌 수 있습니다.

## 한계

- 안전 모드로 부팅하면 이 앱이 꺼져서 막을 수 없습니다.
- 기기 제조사가 설정 앱을 다른 이름(패키지)으로 쓰면 막히지 않을 수 있습니다. (삼성 · 픽셀 · 샤오미 등은 `com.android.settings`)
- 컴퓨터에 연결해 adb로 지우는 것은 막지 못합니다.

## 직접 빌드

```
cd settings-lock-android
gradle assembleRelease   # Gradle 8.9, JDK 17, Android SDK 34
```

APK는 빌드할 때마다 그 기계의 디버그 키로 서명됩니다. 그래서 새 버전이 기존 앱 위에 덮어 설치되지 않으면, **잠금이 꺼져 있을 때** 기존 앱을 지우고 새로 설치하세요.
