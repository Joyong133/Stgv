# 타이머 잠금 (Android)

고른 앱을 열면 **1분 · 3분 · 5분 타이머 화면**이 앱을 덮어서 잠시 사용을 막는 안드로이드 앱입니다.
**화이트리스트**로 체크한 앱은 언제나 바로 사용할 수 있습니다.

## 설치

1. 이 저장소의 **Releases → `타이머 잠금 APK (최신)`** 에서 `TimerLock.apk` 를 휴대폰으로 내려받아 설치합니다.
   (또는 Actions 탭의 빌드 결과 `TimerLock-apk` 아티팩트)
2. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다. Play 프로텍트 경고가 뜨면 "무시하고 설치"를 누릅니다.
3. 앱을 열고 **접근성 설정 열기** → 설치된 앱 → **타이머 잠금** 을 켭니다.
   - 스위치가 회색으로 눌리지 않으면(안드로이드 13 이상 "제한된 설정"): 앱의 **앱 정보 열기** → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 켭니다.

## 사용법

- 앱 목록에서 앱을 누르고 고릅니다.
  - **1분 / 3분 / 5분 타이머**: 그 앱을 열면 타이머 화면이 뜨고, 시간이 끝나야 사용할 수 있습니다.
  - **화이트리스트**: 항상 사용 가능.
  - **제한 없음**
- **화이트리스트 외 모든 앱에 타이머**를 켜면, 화이트리스트로 체크한 앱을 뺀 모든 앱에 *기본 타이머 시간*(1·3·5분)이 걸립니다.
- 위쪽 **타이머 잠금 사용** 스위치로 전체 기능을 잠시 끌 수 있습니다.

### 타이머 동작

- 타이머 화면이 떠 있는 동안 아래 앱은 터치할 수 없습니다. **홈으로 나가기** 버튼으로 나갈 수 있습니다.
- 카운트다운 도중 나갔다가 돌아오면 남은 시간이 이어집니다(처음부터 다시 시작하지 않음).
- 타이머가 끝나면 그 앱을 계속 쓰는 동안은 다시 막지 않습니다. 다른 앱으로 나간 뒤 15초가 지나서 다시 열면 타이머가 또 시작됩니다.
- 홈 화면(런처), 기본 전화 앱, 이 앱 자체는 막지 않습니다. "모든 앱" 모드에서도 설정 앱은 기본으로 막지 않습니다(직접 타이머를 지정하면 막힘).

## 권한

- **접근성 서비스**: 어떤 앱이 화면 앞에 열렸는지(패키지 이름)만 확인하고, 그 위에 타이머 화면을 띄우는 데 씁니다. 화면 내용이나 입력한 글자는 읽지 않으며(`canRetrieveWindowContent=false`), 인터넷 권한이 없어 어떤 정보도 밖으로 보내지 않습니다.

## 직접 빌드

Android Studio로 `timer-lock-app` 폴더를 열거나, Android SDK가 설치된 환경에서:

```bash
cd timer-lock-app
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

`timer-lock-app/` 이나 워크플로가 바뀌어 푸시되면 GitHub Actions(`.github/workflows/timer-lock-apk.yml`)가 자동으로 APK를 빌드해 Release에 올립니다.

> `app/timerlock.keystore` 는 개인 설치용 공개 서명 키입니다(비밀번호 `android`). 같은 키로 서명해야 새 버전을 지우지 않고 덮어 설치할 수 있습니다. 스토어 배포용이 아닙니다.
