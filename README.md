# 메이플 모험기 (Maple Adventure RPG)

메이플스토리의 세계관을 바탕으로 만든 **쯔꾸르(RPG 메이커) 스타일** 2D 탑다운 RPG입니다.
설치 없이 브라우저에서 바로 실행되고, 그림·음악·효과음은 모두 코드로 직접 그리고 합성했습니다.

> 비공식 팬 게임입니다. 넥슨 및 메이플스토리와 관련이 없으며, 원작의 이미지·음원 파일은 사용하지 않았습니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 시작됩니다. 별도 서버나 빌드가 필요 없습니다.

## 조작법

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 십자 버튼 |
| 대화 · 결정 | Z / Space / Enter | A |
| 취소 · 메뉴 | X / Esc | B |
| 달리기 | Shift (누른 채 이동) | 달리기 버튼 (켜고 끄기) |
| 소리 켜고 끄기 | M | 소리 버튼 |

메뉴에서 아이템 · 장비 · 스탯 · 스킬 · 퀘스트를 확인하고, 언제든 **저장**할 수 있습니다 (브라우저 localStorage).

## 게임 내용

- **이야기**: 메이플 아일랜드 암허스트에서 초보자로 시작해, 빅토리아 아일랜드를 여행하며 성장하고, 개미굴 깊은 곳에서 깨어난 **주니어 발록**을 물리치면 엔딩. 엔딩 뒤에도 계속 플레이할 수 있습니다.
- **맵 12곳**: 암허스트, 달팽이 동산, 리스항구, 헤네시스, 헤네시스 사냥터, 버섯 동산, 빅토리아 로드, 엘리니아, 페리온, 커닝시티, 개미굴, 개미굴 깊은 곳
- **전직 (레벨 10)**: 전사(페리온 · 주먹펴고 일어서), 마법사(엘리니아 · 하인즈), 궁수(헤네시스 · 헬레나), 도적(커닝시티 · 다크로드). 직업마다 스킬 4개 + 초보자 스킬(달팽이 세 마리, 리커버리)
- **몬스터 14종**: 달팽이 3색, 슬라임, 주황버섯, 리본돼지, 초록버섯, 스텀프, 뿔버섯, 다크 스텀프, 이블아이, 좀비버섯, 보스 머쉬맘 · 주니어 발록
- **전투**: 필드에서 몬스터에 닿으면 시작되는 턴제 사이드뷰 전투. 메이플식 데미지 숫자, 크리티컬, 버프, 독 · 기절, 보스 전용 패턴
- **성장**: 레벨업 시 AP 5 (자동 배분 또는 수동), 장비 (무기 · 모자 · 옷), 상점 구매 · 판매, 퀘스트 7개, 헤어샵
- **사망 시**: 마지막으로 들른 마을에서 부활 (전직 후에는 경험치 10% 손실)

## 파일 구성

```
index.html        페이지와 터치 컨트롤
css/style.css     레이아웃
js/core.js        화면 · 입력 · 사운드(WebAudio 합성 BGM/효과음) · 그리기 도구
js/art.js         도트 캐릭터 · 아이콘 · 포탈 그리기
js/monsters.js    몬스터 도트
js/tiles.js       지형 타일 · 건물 그리기
js/data.js        직업 · 스킬 · 아이템 · 몬스터 · 성장 공식
js/maps.js        맵 데이터 (ASCII 타일)
js/ui.js          대화창 · 선택지 · 메뉴 · 상점
js/npcs.js        NPC 대사 · 퀘스트 · 전직
js/field.js       필드 이동 · 몬스터 배회 · HUD
js/battledraw.js  전투 배경 · 이펙트 · 데미지 숫자
js/battle.js      턴제 전투
js/main.js        제목 화면 · 저장 · 항해 · 엔딩 · 메인 루프
```

맵은 `js/maps.js`의 문자 지도(`.` 바닥, `T` 나무, `~` 물, `#` 벽 …)를 고치면 바로 바뀌고,
몬스터 능력치와 아이템은 `js/data.js`에서 조정할 수 있습니다.

# 넘김 뷰어 (이미지 순서대로 보기)

`viewer/index.html`을 브라우저로 열면 바로 쓸 수 있는 이미지 뷰어입니다. 설치나 서버가 필요 없고, 파일은 브라우저 안에서만 열립니다.

- **넣는 방법**: 파일 고르기 · 폴더 고르기 · 창에 끌어다 놓기 (JPG, PNG, GIF, WEBP, BMP, AVIF)
- **ZIP · CBZ**: 압축을 풀지 않고 안의 이미지를 바로 봅니다. ZIP 속 ZIP, 윈도우에서 만든 한글 파일 이름(CP949), ZIP64도 읽습니다. `__MACOSX` 같은 군더더기 파일은 빼고 보여 줍니다.
- **순서**: 파일 이름순(숫자는 크기대로: 1, 2, 10) 또는 넣은 순서
- **보기**: 한 장 · 두 장(만화책처럼 펼쳐 보기, 표지 따로, 가로로 긴 펼침면은 혼자) · 세로 스크롤(웹툰)
- **크기**: 화면 맞춤 · 가로 맞춤 · 원본, 넘기는 방향 왼쪽→오른쪽 / 오른쪽→왼쪽
- **조작**: `←` `→` 넘기기, `Space` 다음 장, `Home` `End` 처음 · 끝, `G` 페이지 목록(미리보기), `F` 전체 화면, `H` 메뉴 숨기기. 터치에서는 좌우로 밀거나 화면 양옆을 누르고, 가운데를 누르면 메뉴가 숨겨집니다.

## 안드로이드 앱 (APK)

**설치 파일: [`android/dist/neomgim-viewer.apk`](android/dist/neomgim-viewer.apk)** (Android 7.0 이상)

휴대폰에서 이 파일을 받아 열면 설치됩니다. 처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 할 수 있어요.

- 웹 뷰어(`viewer/index.html`)를 그대로 담은 앱이라 기능이 같습니다. 인터넷 없이 동작하고 파일은 휴대폰 밖으로 나가지 않습니다.
- **파일 고르기**: 사진 · ZIP · CBZ를 여러 개 한 번에 고를 수 있어요.
- **폴더 고르기**: 폴더를 고르면 그 안(하위 폴더 포함)의 이미지와 ZIP을 모두 이름순으로 엽니다.
- **다른 앱에서 열기 · 공유하기**: 파일 앱에서 ZIP이나 사진을 "넘김 뷰어로 열기", 갤러리에서 "공유 → 넘김 뷰어"도 됩니다.
- 전체 화면 버튼이나 화면 가운데를 누르면 상태 표시줄까지 숨기고 봅니다. 뒤로 가기는 목록 · 설정 · 전체 화면을 먼저 닫고, 두 번 누르면 앱이 닫혀요. 보는 동안 화면이 꺼지지 않습니다.

### 직접 빌드하기

Gradle이나 Android Studio 없이 Ubuntu 패키지만으로 만듭니다.

```bash
sudo apt install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23 default-jdk
android/build.sh        # → android/dist/neomgim-viewer.apk
```

`viewer/index.html`을 고친 뒤 다시 빌드하면 앱에도 그대로 반영됩니다. 서명은 저장소에 든 `android/debug.keystore`(비밀번호 `android`)로 하므로, 같은 키로 만든 새 버전은 지우지 않고 덮어 설치됩니다. 스토어에 올릴 때는 따로 만든 키로 바꿔 주세요.
