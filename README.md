# 메이플 모험기 (Maple Adventure RPG)

메이플스토리의 세계관을 바탕으로 만든 **쯔꾸르(RPG 메이커) 스타일** 2D 탑다운 RPG입니다.
설치 없이 브라우저에서 바로 실행되고, 그림·음악·효과음은 모두 코드로 직접 그리고 합성했습니다.

> 비공식 팬 게임입니다. 넥슨 및 메이플스토리와 관련이 없으며, 원작의 이미지·음원 파일은 사용하지 않았습니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 시작됩니다. 별도 서버나 빌드가 필요 없습니다.

## 조작법

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 십자 버튼 |
| 대화 · 결정 | Z / Space / Enter | A |
| 취소 · 메뉴 | X / Esc | B |
| 달리기 | Shift (누른 채 이동) | 달리기 버튼 (켜고 끄기) |
| 소리 켜고 끄기 | M | 소리 버튼 |

메뉴에서 아이템 · 장비 · 스탯 · 스킬 · 퀘스트를 확인하고, 언제든 **저장**할 수 있습니다 (브라우저 localStorage).

## 게임 내용

- **이야기**: 메이플 아일랜드 암허스트에서 초보자로 시작해, 빅토리아 아일랜드를 여행하며 성장하고, 개미굴 깊은 곳에서 깨어난 **주니어 발록**을 물리치면 엔딩. 엔딩 뒤에도 계속 플레이할 수 있습니다.
- **맵 12곳**: 암허스트, 달팽이 동산, 리스항구, 헤네시스, 헤네시스 사냥터, 버섯 동산, 빅토리아 로드, 엘리니아, 페리온, 커닝시티, 개미굴, 개미굴 깊은 곳
- **전직 (레벨 10)**: 전사(페리온 · 주먹펴고 일어서), 마법사(엘리니아 · 하인즈), 궁수(헤네시스 · 헬레나), 도적(커닝시티 · 다크로드). 직업마다 스킬 4개 + 초보자 스킬(달팽이 세 마리, 리커버리)
- **몬스터 14종**: 달팽이 3색, 슬라임, 주황버섯, 리본돼지, 초록버섯, 스텀프, 뿔버섯, 다크 스텀프, 이블아이, 좀비버섯, 보스 머쉬맘 · 주니어 발록
- **전투**: 필드에서 몬스터에 닿으면 시작되는 턴제 사이드뷰 전투. 메이플식 데미지 숫자, 크리티컬, 버프, 독 · 기절, 보스 전용 패턴
- **성장**: 레벨업 시 AP 5 (자동 배분 또는 수동), 장비 (무기 · 모자 · 옷), 상점 구매 · 판매, 퀘스트 7개, 헤어샵
- **사망 시**: 마지막으로 들른 마을에서 부활 (전직 후에는 경험치 10% 손실)

## 파일 구성

```
index.html        페이지와 터치 컨트롤
css/style.css     레이아웃
js/core.js        화면 · 입력 · 사운드(WebAudio 합성 BGM/효과음) · 그리기 도구
js/art.js         도트 캐릭터 · 아이콘 · 포탈 그리기
js/monsters.js    몬스터 도트
js/tiles.js       지형 타일 · 건물 그리기
js/data.js        직업 · 스킬 · 아이템 · 몬스터 · 성장 공식
js/maps.js        맵 데이터 (ASCII 타일)
js/ui.js          대화창 · 선택지 · 메뉴 · 상점
js/npcs.js        NPC 대사 · 퀘스트 · 전직
js/field.js       필드 이동 · 몬스터 배회 · HUD
js/battledraw.js  전투 배경 · 이펙트 · 데미지 숫자
js/battle.js      턴제 전투
js/main.js        제목 화면 · 저장 · 항해 · 엔딩 · 메인 루프
```

맵은 `js/maps.js`의 문자 지도(`.` 바닥, `T` 나무, `~` 물, `#` 벽 …)를 고치면 바로 바뀌고,
몬스터 능력치와 아이템은 `js/data.js`에서 조정할 수 있습니다.

# ChatGPT 챗봇 앱

chatgpt.com 웹사이트와 연동되는 챗봇 앱이 세 가지 있습니다. 모두 **내 ChatGPT 계정을 그대로 쓰므로 API 키가 필요 없습니다.**

## 1. ChatGPT 데스크톱 앱 (`chatgpt-app/`) — Windows · macOS · Linux

chatgpt.com 웹사이트를 전용 앱 창에 띄웁니다. 처음 한 번 로그인하면 다음 실행부터 로그인 상태가 유지됩니다.

```bash
cd chatgpt-app
npm install      # 처음 한 번 (Node.js 18 이상 필요)
npm start        # 앱 실행
npm run dist     # 설치 파일 만들기 (dist/ 폴더에 생성)
```

- **Ctrl+Shift+Space** (Mac은 Cmd+Shift+Space): 어디서든 ChatGPT 창 불러오기/숨기기
- **Ctrl+N** 새 채팅 · **Ctrl+Shift+N** 임시 채팅 · 보기 메뉴에서 확대/축소, 항상 위에 표시
- ChatGPT 밖으로 나가는 링크는 기본 브라우저에서 열림
- 마이크(음성 입력) · 알림 권한은 ChatGPT 관련 사이트에만 허용
- 도움말 → 로그아웃으로 앱에 저장된 로그인 정보를 지울 수 있음

> Google 계정 로그인은 Google 정책상 앱 창 안에서 막힐 수 있습니다. 이 경우 이메일, Microsoft 또는 Apple 계정으로 로그인하세요.

## 2. 안드로이드 앱 APK (`chatgpt-android/`)

chatgpt.com을 앱 화면에 띄우는 안드로이드 앱입니다. (Android 8.0 이상)

**설치:** 휴대폰에서 이 저장소의 **Releases**에 들어가 최신 `ChatGPT.apk`를 내려받아 설치합니다.
처음 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 할 수 있습니다.

- 처음 한 번 로그인하면 로그인 상태가 유지됨
- 사진 · 파일 첨부, 음성 입력(마이크) 지원
- 다른 앱에서 글을 **공유 → ChatGPT**로 보내거나, 글자를 길게 눌러 **ChatGPT에게 묻기**를 누르면 바로 질문
- ChatGPT 밖으로 나가는 링크는 기본 브라우저에서 열림
- 뒤로 가기 버튼으로 이전 화면 이동

**빌드:** `chatgpt-android/` 폴더가 바뀌어 push되면 GitHub Actions(`.github/workflows/android-apk.yml`)가 APK를 만들어 Releases에 올립니다.
직접 빌드하려면 Android Studio로 `chatgpt-android` 폴더를 열거나 `./gradlew assembleRelease`를 실행하세요.

> Google 계정 로그인은 Google 정책상 앱 안에서 막힐 수 있습니다. 이 경우 이메일, Microsoft 또는 Apple 계정으로 로그인하세요.
> APK는 저장소에 들어 있는 테스트용 키(`app/shared.keystore`)로 서명됩니다. 같은 키로 서명해야 새 버전을 덮어 설치할 수 있어서 이렇게 했습니다. Play 스토어에 올리려면 자신만의 키를 새로 만들어 비공개로 보관하세요.

## 3. 웹 챗봇 (`chatbot/`) — 휴대폰 · PC 브라우저

`chatbot/index.html`을 브라우저로 열면 바로 쓸 수 있습니다. 설정에서 연결 방식을 고를 수 있습니다.

| 연결 방식 | 동작 | 필요한 것 |
| --- | --- | --- |
| **ChatGPT 웹사이트** (기본) | 질문을 보내면 chatgpt.com이 열리며 그 질문을 바로 보냄 (`chatgpt.com/?q=질문`) | ChatGPT 로그인 |
| **OpenAI API** | 답변이 이 화면 안에 실시간으로 표시됨 | [API 키](https://platform.openai.com/api-keys) (ChatGPT 구독과 별도 과금) |

- 보낸 질문과 대화 목록이 브라우저(localStorage)에 저장되고, 웹사이트 모드에서는 "ChatGPT에서 다시 열기"를 누를 수 있음
- API 모드: 답변 스트리밍과 중지, 다시 생성, 마크다운 표시와 코드 복사, 모델과 시스템 프롬프트 변경
- 다크 모드와 모바일 화면 지원

> API 키는 사용 중인 브라우저에만 저장되고, 설정한 API 주소로만 전송됩니다.

```
chatgpt-android/        안드로이드 앱 (WebView, Java)
chatgpt-app/main.js     데스크톱 앱 (Electron)
chatbot/index.html      웹 챗봇 화면
chatbot/style.css       스타일 (라이트/다크)
chatbot/app.js          대화 관리 · 웹사이트 연결 · OpenAI API 스트리밍
```
