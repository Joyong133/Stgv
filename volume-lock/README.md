# 볼륨 잠금 (Volume Lock) 안드로이드 앱

소리를 정해 둔 볼륨보다 **줄이지 못하게** 막아 주는 앱입니다.
볼륨 버튼, 알림창 슬라이더, 다른 앱이 소리를 줄여도 바로 원래 볼륨으로 되돌립니다. (올리는 것은 자유)

## 받는 방법
`volume-lock/` 폴더가 바뀌면 GitHub Actions가 자동으로 APK를 빌드해서
저장소의 **Releases → `volume-lock`** 에 `VolumeLock.apk`로 올립니다.

## 사용법
1. APK 설치 (출처를 알 수 없는 앱 설치 허용 필요)
2. 잠글 항목(미디어 / 벨소리 / 알림 / 알람 / 통화) 체크 후 막대로 최소 볼륨 지정
3. **볼륨 잠금 켜기** 스위치 ON → 알림창에 "볼륨 잠금 작동 중" 표시
4. 벨소리·알림을 잠그려면 "방해 금지 권한 허용" 버튼으로 권한을 주세요 (무음/진동 전환도 막음)
5. 잠금이 저절로 꺼지면 앱 배터리 설정을 '제한 없음'으로 바꿔 주세요

휴대폰을 재부팅해도 잠금이 켜져 있었다면 자동으로 다시 시작합니다.
