# 우리집 VR

84㎡ 방 3개 · 욕실 2개 아파트(13층)를 **VR 헤드셋(메타 퀘스트 등), PC, 휴대폰**에서 걸어 다니며
문을 열고, 불을 켜고, 소파에 앉고, 물건을 집어 던지고, 가구를 옮겨 볼 수 있는 가상 집입니다.
three.js + WebXR로 만들었고, 모델·텍스처·소리는 전부 코드로 만들어서 따로 받을 파일이 없습니다.

## 실행 방법

ES 모듈을 쓰기 때문에 `file://`로 열면 안 되고, 웹 서버로 열어야 합니다.

- **퀘스트에서 VR로**: GitHub 저장소 → Settings → Pages → *Deploy from a branch*에서 이 브랜치와 `/ (root)`를 고르고 저장합니다.
  잠시 뒤 퀘스트 브라우저로 `https://joyong133.github.io/Stgv/vr-home/`을 열고 **VR로 들어가기**를 누르세요. (VR은 https 주소에서만 켜집니다.)
- **내 컴퓨터에서**: 저장소 폴더에서 `npx serve .` 또는 `python3 -m http.server`를 실행하고 `http://localhost:…/vr-home/`을 엽니다.

## 조작법

| 동작 | PC | 휴대폰 | VR (퀘스트) |
| --- | --- | --- | --- |
| 걷기 | WASD · 방향키 (Shift 달리기) | 왼쪽 아래를 끌기 | 왼손 스틱 |
| 둘러보기 · 돌기 | 마우스 | 화면 밀기 | 고개 · 오른손 스틱 좌우 (스냅 30°) |
| 순간이동 | 미니맵 · 도면 보기에서 클릭 | 메뉴 → 방으로 이동 | 오른손 스틱을 앞으로 밀었다 놓기 |
| 열기 · 켜기 · 앉기 | 클릭 · E | 탭 | 트리거 |
| 물건 잡기 | 클릭 · E (클릭: 던지기, Q: 내려놓기, F: 쓰기) | 탭 → 아래 버튼 | 그립(또는 트리거) 잡고 놓으며 던지기 |
| 메뉴 | Tab | 메뉴 버튼 | B · Y (손목 메뉴) |

## 집 안에서 할 수 있는 것

- **문**: 방문 6개, 현관문(도어락 소리), 중문, 발코니 미닫이문 2개, 샤워부스 문, 옷장·신발장·싱크대·냉장고 문, 서랍
- **조명**: 방마다 벽 스위치, 현관 월패드의 *일괄 소등*, 스탠드·무드등·책상 스탠드, 엘리베이터 홀 센서등
- **가전**: TV(채널 4개), 블루투스 스피커(음악), 컴퓨터, 전자레인지, 인덕션, 후드, 스탠드·벽걸이 에어컨, 세탁기·건조기, 보일러(바닥 난방)
- **물**: 싱크대·세면대·개수대 수전, 욕조 물 받기/빼기, 샤워기, 변기 물 내리기와 뚜껑
- **앉기 · 눕기**: 소파, 식탁 의자, 사무용 의자, 캠핑 의자, 피아노 의자, 화장대 스툴, 침대에 눕기
- **놀거리**: 디지털 피아노 2옥타브(자동 연주 *작은 별*), 화분 물 주기, 고양이 *나비* 쓰다듬기, 로봇청소기 돌리기, 엘리베이터 부르기
- **물건**: 사과·귤·머그컵·책·쿠션·베개·곰 인형·고무 오리·공·리모컨(TV 채널) 등 집어서 던지기
- **시간 · 날씨**: 실제 시계에 맞춘 낮과 밤(빠르게·멈춤 가능), 맑음·흐림·비·눈, 밤이면 이웃 아파트 창에 불
- **꾸미기**: 방마다 벽 색 12가지, 바닥 8종, 가구 옮기기·돌리기·복제·삭제·추가(22종) — 이 브라우저에 자동 저장
- **보기**: 도면 보기(천장을 걷어 낸 위에서 보기), 미니맵, 방 이름표, 사진 찍기, 욕실·드레스룸 거울

## 내 집에 맞게 고치기

`vr-home/js/layout.js` 한 파일에 평면도가 다 들어 있습니다 (단위 m, x는 서→동, z는 북→남).

- `ROOMS`: 방 이름과 범위 `[x0, z0, x1, z1]`, 바닥 종류, 벽 색
- `WALLS`: 벽과 문·창문 위치 (여닫이 `door`, 미닫이 `slide`, 창 `window`, 통로 `open`)
- `SWITCHES`: 조명 스위치 위치
- `FURNITURE`: 가구 종류·위치·방향 (`rot` 0이면 앞면이 남쪽)

# 메이플 모험기 (Maple Adventure RPG)

메이플스토리의 세계관을 바탕으로 만든 **쯔꾸르(RPG 메이커) 스타일** 2D 탑다운 RPG입니다.
설치 없이 브라우저에서 바로 실행되고, 그림·음악·효과음은 모두 코드로 직접 그리고 합성했습니다.

> 비공식 팬 게임입니다. 넥슨 및 메이플스토리와 관련이 없으며, 원작의 이미지·음원 파일은 사용하지 않았습니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 시작됩니다. 별도 서버나 빌드가 필요 없습니다.

## 조작법

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 십자 버튼 |
| 대화 · 결정 | Z / Space / Enter | A |
| 취소 · 메뉴 | X / Esc | B |
| 달리기 | Shift (누른 채 이동) | 달리기 버튼 (켜고 끄기) |
| 소리 켜고 끄기 | M | 소리 버튼 |

메뉴에서 아이템 · 장비 · 스탯 · 스킬 · 퀘스트를 확인하고, 언제든 **저장**할 수 있습니다 (브라우저 localStorage).

## 게임 내용

- **이야기**: 메이플 아일랜드 암허스트에서 초보자로 시작해, 빅토리아 아일랜드를 여행하며 성장하고, 개미굴 깊은 곳에서 깨어난 **주니어 발록**을 물리치면 엔딩. 엔딩 뒤에도 계속 플레이할 수 있습니다.
- **맵 12곳**: 암허스트, 달팽이 동산, 리스항구, 헤네시스, 헤네시스 사냥터, 버섯 동산, 빅토리아 로드, 엘리니아, 페리온, 커닝시티, 개미굴, 개미굴 깊은 곳
- **전직 (레벨 10)**: 전사(페리온 · 주먹펴고 일어서), 마법사(엘리니아 · 하인즈), 궁수(헤네시스 · 헬레나), 도적(커닝시티 · 다크로드). 직업마다 스킬 4개 + 초보자 스킬(달팽이 세 마리, 리커버리)
- **몬스터 14종**: 달팽이 3색, 슬라임, 주황버섯, 리본돼지, 초록버섯, 스텀프, 뿔버섯, 다크 스텀프, 이블아이, 좀비버섯, 보스 머쉬맘 · 주니어 발록
- **전투**: 필드에서 몬스터에 닿으면 시작되는 턴제 사이드뷰 전투. 메이플식 데미지 숫자, 크리티컬, 버프, 독 · 기절, 보스 전용 패턴
- **성장**: 레벨업 시 AP 5 (자동 배분 또는 수동), 장비 (무기 · 모자 · 옷), 상점 구매 · 판매, 퀘스트 7개, 헤어샵
- **사망 시**: 마지막으로 들른 마을에서 부활 (전직 후에는 경험치 10% 손실)

## 파일 구성

```
index.html        페이지와 터치 컨트롤
css/style.css     레이아웃
js/core.js        화면 · 입력 · 사운드(WebAudio 합성 BGM/효과음) · 그리기 도구
js/art.js         도트 캐릭터 · 아이콘 · 포탈 그리기
js/monsters.js    몬스터 도트
js/tiles.js       지형 타일 · 건물 그리기
js/data.js        직업 · 스킬 · 아이템 · 몬스터 · 성장 공식
js/maps.js        맵 데이터 (ASCII 타일)
js/ui.js          대화창 · 선택지 · 메뉴 · 상점
js/npcs.js        NPC 대사 · 퀘스트 · 전직
js/field.js       필드 이동 · 몬스터 배회 · HUD
js/battledraw.js  전투 배경 · 이펙트 · 데미지 숫자
js/battle.js      턴제 전투
js/main.js        제목 화면 · 저장 · 항해 · 엔딩 · 메인 루프
```

맵은 `js/maps.js`의 문자 지도(`.` 바닥, `T` 나무, `~` 물, `#` 벽 …)를 고치면 바로 바뀌고,
몬스터 능력치와 아이템은 `js/data.js`에서 조정할 수 있습니다.
