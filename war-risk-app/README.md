# 남북 위험도 (안드로이드 앱)

전 세계 뉴스에서 북한·남북 군사 관련 기사를 모아, 한반도 무력충돌 위험도를 **0~100점**과
**관심 · 주의 · 경계 · 심각** 4단계로 보여주는 앱입니다.

## 설치

[Releases의 `war-risk-latest`](../../releases/tag/war-risk-latest)에서 `WarRisk.apk`를 휴대폰으로 내려받아 설치하세요.
(처음 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.)

## 기능

- **전 세계 뉴스 수집**: Google 뉴스 9개 지역판(한국·미국·영국·일본·중국·러시아·독일·프랑스·스페인어권)과
  GDELT(전 세계 65개 언어 뉴스 모니터링)에서 최근 72시간 기사를 가져옵니다.
- **위험 지수 계산**: 기사 제목에서 8개 언어의 위험 신호(교전, 사상자, 포격, 핵실험, 침범, 대피령, 미사일, 도발 …)를 찾고,
  최신 기사일수록, 여러 언론이 함께 보도할수록 크게 반영합니다. 회담·대화 보도는 점수를 깎습니다.
- **각국 대사관 철수 소식**: 서울·평양 주재 대사관의 철수·폐쇄·대피, 자국민 출국 권고·여행금지 보도를
  6개 언어 전용 검색으로 따로 찾아 나라별로 보여줍니다(예: "미국 — 대사관 철수 · 서울(한국) · 기사 3건").
  대피 훈련, 공관 재개, 북한의 해외 공관 정리, 다른 나라(이스라엘·우크라이나 등)에서의 철수는 제외합니다.
  가장 무거운 위험 신호(서울 대사관 철수 45, 자국민 철수 30, 평양 대사관 철수 15)로 반영하고,
  처음 보는 나라의 철수 소식이 나오면 바로 알림을 보냅니다.
- **군 경계태세 (데프콘)**: 데프콘 5~1 눈금에 현재 단계를 표시합니다. 한반도의 실제 데프콘은 군사기밀이라
  실시간 공개되지 않으므로, 뉴스에 "데프콘 3 발령"처럼 단계가 보도되면 가장 최근 보도를, 없으면 평시 기본값(데프콘 4)을
  보여줍니다. 진돗개(평시 셋)·통합방위사태·워치콘 보도도 함께 찾습니다. 방송인 '데프콘', 해킹대회 'DEF CON',
  "격상 가능성" 같은 추측 기사, 1976년 회고 기사는 제외합니다. 격상 보도가 나오면 알림을 보내고 전쟁 가능성에도 반영합니다.
- **전쟁 가능성 (향후 30일 추정)**: 위험 지수와 대사관 철수, 최근 급상승을 합쳐 확률(%)로 보여주고,
  각 요인이 가능성을 몇 배 올렸는지도 보여줍니다.
- **점수 근거 표시**: 어떤 신호가 몇 건 잡혀서 몇 점이 됐는지 막대로 보여줍니다.
- **추이 그래프**: 확인할 때마다 점수를 기록해 변화를 보여줍니다.
- **자동 확인 + 알림**: 앱을 닫아도 30분/1시간/3시간/6시간마다 확인하고, 위험 단계가 정한 기준(주의/경계/심각) 이상으로
  올라가면 알림을 보냅니다.
- 기사를 누르면 원문이 브라우저로 열립니다. "위험 신호 기사만", "위험한 순" 정렬도 됩니다.

## 점수 계산 방식

1. 북한·남북·한반도와 관련 없는 기사는 버리고, 제목이 같은 기사는 하나로 합칩니다.
2. 신호마다 잡힌 기사의 최신도 가중치(18시간마다 약 1/e로 감소)를 더해 보도 강도를 구합니다.
3. 신호 점수 = 가중치 × (1 − e^(−보도강도/1.5)) → 기사 1건이면 절반쯤, 3~4건 이상이면 거의 전부 반영.
4. 지수 = 100 × (1 − e^(−(위험 신호 합 − 완화 신호 합)/45)).
5. 북한군 러시아 파병처럼 한반도 밖 전쟁 기사는 강한 신호(교전·사상자 등)를 세지 않습니다.

## 전쟁 가능성 계산 방식

로지스틱 모형으로 어림합니다: 가능성 = 1 / (1 + e^(−z))

```
z = −6.2                                   (평시 약 0.2%/30일: 1953년 정전 이후 전면전 없음)
  + 0.045 × 위험 지수
  + 1.0 × 서울 대사관 철수 국가 수 (최대 3)
  + 0.6 × 자국민 철수·여행금지 국가 수 (최대 3)
  + 0.3 × 평양 대사관 철수 국가 수 (최대 2)
  + 0.015 × 1~3일 전 평균보다 오른 점수 (최대 40)
  + 보도된 경계태세: 데프콘 3/2/1 → 1.0/2.0/3.0, 통합방위사태 갑/을/병 → 1.5/0.8/0.3,
                    진돗개 하나 → 0.4, 워치콘 2/1 → 0.3/0.6   (기사 1건뿐이면 절반)
```
철수 국가는 기사 2건 이상이면 1개국, 1건뿐이면 0.5개국으로 셉니다(오보 한 건에 크게 흔들리지 않게).

| 상황 (예시 기사로 시험) | 위험 지수 | 전쟁 가능성 |
| --- | --- | --- |
| 평시 | 0 | 0.2% |
| 탄도미사일 발사 | 28 | 0.8% |
| 핵실험 + ICBM | 54 | 3.7% |
| 교전 + 사상자 | 83 | 13% |
| 교전 + 여러 나라 대사관·자국민 철수 | 93 | 51% |

과거 자료로 검증한 예측 모델이 아니라 크기 감각을 잡기 위한 어림값입니다.

## 위험 단계

| 단계 | 점수 | 예시 상황 |
| --- | --- | --- |
| 관심 | 0~24 | 특별한 군사 행동 보도 없음 |
| 주의 | 25~49 | 탄도미사일 발사, 도발 |
| 경계 | 50~74 | 핵실험 + ICBM, 포격·침범 |
| 심각 | 75~100 | 교전, 사상자, 주민 대피 |

> 이 앱은 뉴스 제목의 단어를 세어 만든 **참고용 지표**이며 정부의 공식 경보가 아닙니다.
> 실제 위급 상황에서는 재난문자, 안전디딤돌 앱, 국방부·합동참모본부 발표를 따르세요.

## 빌드

`war-risk-app/` 아래를 수정해 푸시하면 GitHub Actions(`.github/workflows/war-risk-apk.yml`)가 APK를 빌드해
`war-risk-latest` 릴리스에 올립니다. 로컬에서는 Android SDK가 있는 환경에서 `./gradlew assembleRelease`.

- 언어: Java, 외부 라이브러리 없음 (minSdk 26 / Android 8.0 이상)
- 주요 파일: `RiskEngine.java`(신호·점수), `EmbassyDetector.java`(대사관 철수 판정), `WarOdds.java`(전쟁 가능성), `AlertStatusDetector.java`(데프콘 등 경계태세 보도), `NewsFetcher.java`(수집), `Checker.java`(주기 확인·알림), `MainActivity.java`(화면)
