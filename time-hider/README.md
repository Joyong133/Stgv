# 시간 숨기기 (Time Hider)

휴대폰 화면에서 **시간 표시를 잠시 안 보이게** 가리는 안드로이드 앱입니다.
켜 두는 동안 상태표시줄 시계, 잠금화면 시계, 알림창 시계, 알림 시각, 앱 안의 시간 글자를 검은 상자로 덮습니다.

## 내려받기

GitHub 저장소의 **Releases → `시간 숨기기 APK`** 에서 `TimeHider.apk` 를 내려받아 설치하세요.
(코드를 고쳐 올리면 GitHub Actions가 자동으로 새 APK를 만들어 올립니다.)

## 처음 설정

1. APK 설치 (출처를 알 수 없는 앱 설치 허용 필요)
2. 앱을 열고 **[접근성 설정 열기]** → 설치된 앱 → **시간 숨기기** → 사용
   - 안드로이드 13 이상에서 '제한된 설정'이라고 막히면: 앱의 **[앱 정보 열기]** → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도
3. **[지금 시간 숨기기]** 를 누르면 바로 적용
4. (선택) 알림창 빠른 설정 편집에서 **시간 숨기기** 타일을 추가하면 한 번에 켜고 끌 수 있습니다

## 기능

| 옵션 | 하는 일 |
| --- | --- |
| 숨기는 시간 | 직접 끌 때까지 / 30분 / 1·2·4·8시간 뒤 자동으로 꺼짐 |
| 상태표시줄 통째로 가리기 | 화면 맨 위 줄을 검게 덮음 (가장 확실한 방법) |
| 시계·시간 자동으로 가리기 | `3:45`, `오후 3시`, `9 AM`, `5분 전` 같은 글자와, 이름이 clock·time인 화면 요소(그림 시계, 시계 위젯, 알림 시각 칸)를 찾아 덮음. 잠금화면·알림창·앱 모두 |
| 잠금화면 · AOD 위쪽 통째로 가리기 | 잠금화면에서 위쪽 일정 비율(기본 35%, 10~80%)을 덮음. 화면이 꺼질 때 위쪽 70%를 미리 덮어 두어 켜는 순간에도 시계가 안 보임 |

옵션은 처음부터 모두 켜져 있습니다.

## 앱이 못 가리는 것

- **AOD(Always On Display)**: 화면이 꺼진 상태에서도 위쪽을 덮어 두지만, 기종에 따라 AOD 화면 위에는 다른 앱이 그릴 수 없습니다. 그럴 때는 앱의 **[AOD 설정 열기]**에서 AOD를 꺼 주세요. 안드로이드가 다른 앱이 AOD를 끄는 걸 허락하지 않습니다.
- 알림창을 내리거나 새 화면을 열 때, 시간을 찾아 덮기까지 아주 짧은 순간(수십 ms)이 걸릴 수 있습니다.
- 스크롤하는 동안에는 시간이 움직일 길까지 넉넉하게 덮기 때문에 검은 상자가 잠깐 세로로 길어 보입니다.
- 동영상이나 사진 속에 찍힌 시계는 찾지 못합니다.

## 개인정보

화면 내용은 시간 글자의 위치를 찾는 데만 쓰이며, 저장하거나 밖으로 보내지 않습니다. 앱에 인터넷 권한이 없습니다.

## 직접 빌드

```
cd time-hider
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

Android SDK(compileSdk 35)와 JDK 17 이상이 필요합니다. 최소 안드로이드 8.0(API 26).
