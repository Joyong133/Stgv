# 수호기사 방어전 (Guardian Knights Defense)

세븐나이츠의 **방어전**에서 영감을 받은 가로 화면 타워 디펜스 게임입니다.
안드로이드 APK(`dist/GuardianKnights-Defense.apk`)로 설치하거나, `defense/index.html`을 브라우저로 열어 바로 플레이할 수 있습니다.

> 비공식 팬메이드 게임입니다. 원작의 이미지 · 음원은 쓰지 않았고, 캐릭터 · 몬스터 · 이펙트 · 효과음 · 배경음은 모두 코드로 직접 그리고 합성했습니다.
> 글꼴: BM JUA, Black Han Sans (SIL Open Font License, `fonts/` 폴더에 라이선스 포함)

## 설치 (안드로이드)

1. `dist/GuardianKnights-Defense.apk`를 휴대폰으로 옮깁니다.
2. 파일을 눌러 설치합니다. (처음이면 "출처를 알 수 없는 앱 설치" 허용 필요)
3. 안드로이드 7.0 이상, 가로 화면 전용입니다.

## 게임 방법

- 왼쪽 아래 **성**을 지키는 게임입니다. 적은 오른쪽 위 포탈에서 나와 길을 따라 성으로 걸어갑니다.
- 아래쪽 영웅 카드를 누른 뒤 **돌 원판(배치 자리)** 을 누르면 영웅이 배치됩니다. 배치에는 **보급(파란 수정)** 이 듭니다.
- 적을 처치하면 보급이 쌓입니다. 배치한 영웅을 누르면 **강화(+1~+5)**, **회수**, **스킬 사용**을 할 수 있습니다.
- 배치된 영웅 카드를 누르면 스킬을 직접 쓸 수 있고, **AUTO** 를 켜면 자동으로 씁니다. 속도는 ×1 / ×2 / ×3.
- 적이 성에 닿으면 성 체력이 줄고, 0이 되거나 **최종 보스**가 성에 닿으면 패배합니다.

### 난이도

| 난이도 | 최종 라운드 | 맵 | 해금 |
| --- | --- | --- | --- |
| 쉬움 | 30 | 초원 | 처음부터 |
| 보통 | 45 | 단풍 협곡 | 쉬움 클리어 |
| 어려움 | 60 | 얼어붙은 요새 | 보통 클리어 |
| 헬 | 100 | 마계 관문 | 어려움 클리어 |

10라운드마다 보스(화염 드래곤 · 빙결 거인 · 폭풍 그리폰 · 타락 천사 · 리치 왕), 5라운드마다 정예,
마지막 라운드에는 **마왕 바알제**가 등장합니다. 보스마다 포효(영웅 기절) · 방벽 · 돌진 · 치유 · 소환 패턴이 있습니다.

### 무한 방어전

쉬움을 클리어하면 열리는 끝없는 모드입니다 (밤의 전장). 몇 라운드까지 버티는지가 기록으로 남습니다.

### 적의 특성

- 유령: 일반 공격 30% 회피 / 고블린 주술사: 주변 적 치유 / 철갑충: 일반 공격 피해 40% 감소 (마법형 · 스킬은 무시)
- 라운드 시작 전에 나올 적과 수, 특성이 표시되고, 아래 영웅 카드에 **▲유리 / ▼불리** 속성 표시가 뜹니다.

### 속성

불 › 바람 › 물 › 불 (유리하면 피해 1.5배, 불리하면 0.75배), 빛 ↔ 어둠 (서로 1.5배).
라운드 시작 전에 다음 라운드 적의 주 속성이 표시됩니다.

### 등급 · 성장

- 등급: **3성 → 4성 → 5성 → 6성 → 각성**
- 최대 레벨: 3성 30 · 4성 40 · 5성 50 · 6성 60 · 각성 70 (진화해도 레벨은 유지)
- 진화: 최대 레벨 + 진화석 + 골드. 각성: 6성 60레벨 + 각성석 30 + 진화석 80 + 골드
- 각성하면 공격력 배율 3.2배, 각성 스킬 해금, 스킬 쿨타임 15% 감소, 사거리 증가, 오라 · 날개 · 후광 외형
- 진화석: 보스 · 정예 처치, 5라운드마다, 중복 소환 / 각성석: 보통 이상 난이도 보스
- 소환: 루비 100 (10회 900, 4성 이상 1명 보장). 확률 3성 70% · 4성 24% · 5성 5% · 6성 1%

### 그 밖의 기능

- **장비**: 영웅마다 무기(공격력) · 반지(공격 속도) · 망토(치명타) 3칸, 최대 +15
- **도감 보너스**: 보유 영웅 1명당 공격력 +1%, 각성 영웅은 +3%
- **상점**: 매일 무료 루비, 골드 · 진화석 · 각성석 구매 (매일 초기화)
- **임무**: 일일 임무 6개 + 전부 완료 보너스, 업적 16개
- **출석 보상**: 7일 주기
- **첫 전투 튜토리얼**, 전투 중 영웅 **이동**, 그래픽 품질 설정

### 저장

- 모든 진행(영웅, 재화, 편성, 기록, 설정)은 자동 저장됩니다. 앱에서는 기기 내부 저장소(SharedPreferences)와 WebView 저장소에 함께 저장합니다.
- 방어전 도중 나가도 **현재 라운드 시작 시점**부터 이어하기가 가능합니다.


## APK 다시 빌드하기

Java 17 이상만 있으면 됩니다 (Android SDK 불필요).

```
./tools/build_apk.sh
```

Maven Central에서 apktool(aapt2 · smali 포함)과 apksig를 받아 `defense/`를 앱 assets 로 묶고,
`android/release.keystore`로 서명해 `dist/GuardianKnights-Defense.apk`를 만듭니다.
같은 키로 서명하므로 새로 빌드한 APK를 덮어 설치해도 저장 데이터가 유지됩니다.
