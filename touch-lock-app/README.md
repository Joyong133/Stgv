# 터치 잠금 (Touch Lock) 안드로이드 앱

영상 보는 중이나 아이에게 폰을 줄 때, **화면 터치를 잠깐 막아 주는** 작은 앱입니다.

- 화면 가장자리에 떠 있는 🔒 버튼을 **두 번** 누르면 → 화면 전체 터치가 잠깁니다.
- 잠긴 동안 화면 오른쪽에 생기는 🔓 버튼을 **두 번** 누르면 → 다시 터치됩니다.
- 한 번만 누르면 버튼이 주황색으로 잠깐 바뀌며 "한 번 더"를 알려 줍니다 (실수로 잠기거나 풀리지 않음).
- 🔒 버튼은 끌어서 원하는 곳으로 옮길 수 있습니다.
- 🔓 버튼이 안 눌릴 때는 알림창을 내려 **[잠금 해제]**, 버튼을 없애려면 **[끄기]**.

## 설치

1. `touch-lock.apk` 를 폰으로 받아 실행 (출처를 알 수 없는 앱 설치 허용 필요)
2. 앱을 열고 **1단계: 다른 앱 위에 표시 허용하기** → 목록에서 "터치 잠금" 허용
3. **잠금 버튼 켜기** → 🔒 버튼이 화면에 뜹니다

안드로이드 8.0 (API 26) 이상에서 동작합니다.

## 한계

안드로이드 보안 정책상 **상태바(알림창 내리기), 홈·뒤로가기 버튼/제스처, 전원·볼륨 버튼은 막을 수 없습니다.**
이 앱은 앱 화면 영역의 터치만 막습니다.

## 빌드

Android SDK나 Gradle 없이 JDK 17+, python3, zip 만으로 빌드됩니다.

```
./build.sh        # → build/touch-lock.apk
```

| 파일 | 내용 |
| --- | --- |
| `AndroidManifest.xml` | 앱 정보 · 권한 |
| `src/.../MainActivity.java` | 설명 · 권한 허용 · 켜기/끄기 화면 |
| `src/.../LockService.java` | 떠 있는 🔒 버튼, 터치 차단 막, 🔓 해제 버튼 |
| `tools/axml.py` | 매니페스트를 바이너리 XML로 변환 (aapt2 대체) |
| `tools/Sign.java` | APK 서명 (apksig) |
| `touchlock.p12` | 서명 키 (암호 `touchlock`). 같은 키로 빌드해야 기존 설치 위에 업데이트됩니다 |
