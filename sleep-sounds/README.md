# 단잠 🌙 — 빗소리 · 수면 사운드 앱

온갖 빗소리와 잠들기 좋은 자연·생활 소리 58가지를 골라 **섞어서** 들을 수 있는 안드로이드 앱입니다.
이어폰을 끼면 **3D 공간 음향**으로 빗소리는 머리 위와 사방에서, 모닥불은 발치 앞에서, 벽시계는 왼쪽 벽에서 들립니다.

소리는 녹음 파일이 아니라 앱 안에서 **실시간으로 합성**합니다. 그래서 APK가 약 150KB로 작고,
몇 시간을 틀어 두어도 같은 구간이 되풀이되지 않습니다.

## 설치

1. [`release/danjam.apk`](release/danjam.apk)를 휴대폰으로 내려받습니다.
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다.
3. Android 7.0 이상에서 동작합니다. 예전 버전을 쓰고 있었다면 지우지 않고 그대로 덮어 설치하면 됩니다 (저장한 믹스가 남아 있어요).

## 기능

- **섞어 듣기**: 타일을 누르면 켜지고 다시 누르면 꺼집니다. 켜진 소리마다 음량 막대가 생깁니다. 길게 누르면 소리 설명이 나옵니다.
- **🎧 3D 공간 음향**: 이어폰을 연결하면 자동으로 켜집니다 (항상 켜기 / 끄기도 가능).
  - **소리 배치판**: 머리를 위에서 내려다본 판에서 소리를 끌어 방향과 거리를 바꿉니다. 두 번 누르면 원래 자리로.
  - **움직임**: 멈춤 / 살랑살랑(제자리 주변에서 천천히 흔들림) / 감싸기(2분쯤에 한 바퀴 머리 둘레를 돎).
  - **공간감**: 잔향의 양 (좁은 방 ↔ 넓은 공간).
- **소리 설정**: 전체 음량, 소리 톤(부드럽게 ↔ 선명하게), 자연스러운 변화(소리마다 음량이 수십 초에 걸쳐 조금씩 오르내림).
- **🔒 다른 앱 소리 막기** (항상 켜진 고정 기능): 단잠이 재생되는 동안 유튜브·음악 앱·브라우저 영상이 소리를 내면 바로 멈춥니다.
  자기 전에 영상을 다시 켜지 않도록 돕는 기능이에요. 끌 수 없이 늘 켜져 있고, 전화·알람·내비게이션 안내는 막지 않으며, 단잠을 멈추면 다시 자유롭게 틀 수 있습니다.
  - 기본: 다른 앱이 소리를 가져가면 단잠이 오디오 포커스를 곧바로 되찾아, 그 앱이 스스로 멈추게 합니다 (권한 필요 없음).
  - 더 확실하게: '알림 접근'을 허용하면 다른 앱의 재생 버튼을 단잠이 직접 눌러 멈춥니다. 알림 내용은 읽지 않습니다.
    APK로 설치한 경우 안드로이드 13부터는 먼저 앱 정보 → ⋮ → '제한된 설정 허용'을 눌러야 허용할 수 있습니다.
- **🎯 집중 소리**: 들을 소리(지금 켜 둔 소리 · 추천 믹스 · 내 믹스)와 시간(15분 ~ 8시간)을 먼저 정하고 시작하면,
  그 시간이 끝날 때까지는 정한 소리만 들을 수 있습니다. 끝나면 소리를 끄거나(천천히 작아지며) 계속 듣도록 고를 수 있어요.
  - 집중하는 동안: 소리를 켜고 끄기 · 믹스 바꾸기 · 일시정지 · 끄기 · 타이머가 앱, 알림창, 잠금화면, 이어폰 단추 어디서도 잠깁니다.
    다른 앱의 음악·영상 소리는 막고, 음량과 3D 설정은 바꿀 수 있습니다.
  - 전화·보이스톡·알람이 오면 잠깐 멈췄다가 끝나면 이어서 들려줍니다. 이어폰이 빠지면 멈추는 대신 소리만 꺼 두고, 다시 끼우면 이어서 들려줍니다.
  - 앱을 끄거나 시스템이 정리해도 남은 시간은 그대로 흐르고, 다시 살아나면 이어서 재생합니다. 시계를 앞으로 돌려도 일찍 끝나지 않아요.
  - 시작하면 끝날 때까지 중간에 풀 수 없어요 (긴급 해제 없음). 시작 전에 시간을 잘 골라 주세요.
- **🌬️ 호흡 안내**: 4-7-8 호흡, 편안한 호흡(4초 들이쉬고 6초 내쉬기), 상자 호흡. 원을 따라 숨을 쉬고, 눈을 감아도 숨결 소리로 따라 할 수 있습니다.
- **🌙 취침 화면**: 검은 바탕에 아주 어두운 시계와 남은 타이머만. 밝기를 최저로 낮추고 화면 자국이 남지 않게 조금씩 움직입니다.
- **추천 믹스 19가지**: 비 오는 날 캠핑, 한옥에서 듣는 비, 피아노와 빗소리, 눈 오는 산장, 깊은 바다 여행, 산사의 밤 …
- **내 믹스**: 지금 듣는 조합을 저장하고, 길게 눌러 이름 바꾸기 · 지금 조합으로 바꾸기 · 삭제.
- **잠들기 타이머**: 10분 ~ 8시간. 끝나기 전 1 / 5 / 15 / 30분 동안 천천히 작아진 뒤 꺼집니다.
  타이머가 흐르는 동안에는 두 곳에서 시간을 더할 수 있어요 — 재생 막대 위에 뜨는 **+10분 · +30분 · +1시간** 버튼, 그리고
  타이머 버튼을 다시 누르면 나오는 "+10분 더하기 / +30분 더하기 / +1시간 더하기" 항목. 잠이 덜 왔을 때 바로 늘릴 수 있고,
  소리가 작아지던 중이었다면 다시 원래 음량으로 돌아갑니다.
- **화면이 꺼져도 재생**: 알림창과 잠금화면에서 재생/일시정지/끄기. 이어폰을 뽑으면 멈추고, 전화가 오면 잠시 멈췄다가 통화가 끝나면 다시 재생합니다.

## 2.0 에서 달라진 점

- **어색하던 소리 고침**: 실제 환경음 녹음 데이터셋(ESC-50)의 빗소리·파도·모닥불·새·풀벌레·개구리·천둥 등 480개 녹음과
  주파수 분포, 음색, 세기 변화, 리듬을 비교해서 벗어난 소리를 고쳤습니다. 예를 들어
  - 이슬비·보슬비가 '쉬-' 하는 잡음처럼 너무 밝았던 것 → 실제 비처럼 200Hz~7kHz 에 고르게 퍼지고 방울마다 음색이 다르게
  - 모닥불이 낮게 웅웅거리기만 하던 것 → '타닥타닥' 밝은 튐 소리가 중심이 되게
  - 천둥이 휴대폰 스피커로는 거의 안 들리던 것 → 실제 천둥처럼 100~500Hz 에 힘이 실리게
  - 파도의 거품이 지직거리던 것, 시냇물이 '뽀록뽀록' 전자음 같던 것, 새소리 사이가 텅 비던 것, 풀벌레·개구리가 너무 기계적으로 반복되던 것
- 새 소리 21가지, 추천 믹스 7가지
- 3D 공간 음향, 소리 배치판, 소리 설정, 호흡 안내, 취침 화면, 믹스 이름 바꾸기·덮어쓰기, 소리 설명, 타이머 페이드 길이 선택

## 소리를 만드는 방법

`app/src/main/java/com/joyong133/danjam/audio/` 에 합성기가 있습니다 (안드로이드에 의존하지 않는 순수 자바).

- **빗소리** (`RainGen`): 멀리서 쏟아지는 '쏴아' 바탕(핑크 노이즈를 200Hz~7kHz 로 거름), 가까이 떨어지는 빗방울
  (방울마다 다른 공명), 빗방울이 두드리는 표면(양철·기와·유리·천막·비닐·자동차 지붕), 웅덩이 기포와 처마 낙숫물,
  빗길을 지나는 자동차를 층별로 조합합니다. 몇 초·몇십 초 단위로 세기가 출렁여 실제 비처럼 살아 있습니다.
- **물방울·기포** (`Bubbles`): 주파수가 살짝 올라가며 사라지는 사인파(민나어트 공명).
- **새·개구리·고래·부엉이** (`Chirps`): 높이가 미끄러지는 음에 떨림·펄스·배음을 더해 울음과 노래를 만듭니다.
- **싱잉볼·범종·풍경·오르골·피아노** (`Rings`): 배음마다 다른 속도로 사라지는 공명음. 범종은 두 음이 겹쳐 생기는 맥놀이까지 냅니다.
- **3D 공간 음향** (`Spatializer`, `PointSource`): Brown·Duda 의 구형 머리 모델로 두 귀의 시간 차(최대 0.66ms),
  머리 그림자(반대편 귀의 높은 소리 감쇠), 귓바퀴의 고도·앞뒤 단서, 거리에 따른 감쇠와 공기 흡수를 계산합니다.
  넓은 소리는 앞뒤 네 점에 퍼뜨려 사방을 감싸게 합니다.
- `Mixer`가 여러 소리를 섞고, 3D 배치·공용 잔향·톤 조절을 거친 뒤 리미터로 소리가 깨지지 않게 합니다.

## 직접 빌드하기

**Android Studio**: `sleep-sounds` 폴더를 열고 실행하면 됩니다.

**명령줄 (Gradle)**:

```sh
cd sleep-sounds
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

**명령줄 (Gradle 없이)**: Android SDK 도구(aapt2, d8 또는 dx, zipalign, apksigner)만 있으면 됩니다.

```sh
cd sleep-sounds
ANDROID_JAR=$ANDROID_HOME/platforms/android-35/android.jar tools/build-apk.sh   # release/danjam.apk
```

`sleep-sounds/` 아래가 바뀌어 푸시되면 GitHub Actions(`.github/workflows/sleep-sounds-apk.yml`)가
APK를 빌드해 아티팩트로 올립니다.

## 서명 키에 대해

`keystore/danjam.jks`는 **개인 설치용** 키입니다. 같은 키로 서명해야 새 버전을 지우지 않고 덮어 설치할 수 있어서
저장소에 함께 넣어 두었습니다. 저장소가 공개되어 있으면 누구나 이 키로 서명할 수 있으니,
Play 스토어 등에 배포할 때는 새 키를 만들어 따로 보관하세요.
