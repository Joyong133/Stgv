# 코프룰루 전선 (Koprulu Front)

스타크래프트의 세계를 바탕으로 만든 **실시간 전략(RTS)** 게임입니다. 테란 사령관이 되어 기지를 세우고,
몰려오는 저그 군단(컴퓨터)을 막아낸 뒤 저그 건물을 모두 부수면 승리합니다.
설치 없이 브라우저에서 바로 실행되고, 그림과 효과음은 모두 코드로 직접 그리고 합성했습니다.

> 비공식 팬 게임입니다. 블리자드 엔터테인먼트 및 스타크래프트와 관련이 없으며, 원작의 이미지·음원 파일은 사용하지 않았습니다.

## 실행 방법

`starcraft/index.html`을 브라우저로 열면 바로 시작됩니다. 별도 서버나 빌드가 필요 없습니다.

## 게임 내용

- **맵**: 96×96 타일, 매번 바위 지형이 새로 만들어지는 점대칭 맵. 본진 언덕과 경사로, 앞마당을 포함한 기지 자리 8곳
- **테란 (플레이어)**: SCV · 마린 · 파이어뱃 · 메딕 · 시즈 탱크 / 커맨드 센터 · 서플라이 디폿 · 리파이너리 · 배럭 · 엔지니어링 베이 · 벙커 · 아카데미 · 팩토리
- **저그 (컴퓨터)**: 드론 · 저글링 · 히드라리스크 · 울트라리스크 · 오버로드 / 해처리 · 스포닝 풀 · 익스트랙터 · 히드라리스크 덴 · 울트라리스크 동굴 · 성큰 콜로니
- **연구**: 스팀팩, U-238 탄, 보병 무기·장갑 3단계, 시즈 모드
- **스타크래프트 1 규칙**: 피해 유형(일반·폭발·진동)과 유닛 크기, 방어력, 보급품, 시야 안개, 저그 애벌레·점막·재생, 테란 건물 화재, SCV 수리, 벙커 사거리 +1, 시즈 탱크 최소 사거리와 범위 피해
- **컴퓨터**: 실제로 자원을 캐고 건물을 짓는 저그. 난이도(쉬움·보통·어려움)에 따라 첫 공격 시각, 공격 규모, 애벌레 속도, 확장 시점이 달라집니다
- **승패**: 저그 건물을 모두 부수면 승리, 테란 건물이 모두 무너지면 패배

## 파일 구성

```
index.html      페이지 · 콘솔 · 타이틀/메뉴 화면
css/style.css   레이아웃
js/util.js      상수 · 수학 · 노이즈 · 저장
js/data.js      유닛 · 건물 · 연구 · 난이도 수치
js/map.js       맵 생성 · 길찾기(A*) · 시야 안개 · 점막
js/entities.js  유닛 · 건물 동작 (이동 · 전투 · 채취 · 건설 · 생산)
js/ai.js        저그 컴퓨터
js/art.js       지형 · 유닛 · 건물 · 효과 · 아이콘 그리기
js/render.js    카메라 · 화면 그리기 · 미니맵
js/audio.js     WebAudio 효과음 합성
js/input.js     선택 · 명령 · 마우스/터치/키보드
js/ui.js        자원 표시 · 선택 정보 · 명령 버튼 · 화면 전환
js/main.js      새 게임 준비 · 메인 루프
```

유닛·건물 능력치와 난이도는 `js/data.js`에서, 컴퓨터의 운영 방식은 `js/ai.js`에서 바로 조정할 수 있습니다.
